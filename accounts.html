🏦 계좌 등록 비교

회준·보현의 통장·카드를 따로 등록해 내역을 올리면, 통장끼리 옮긴 돈을 찾아 빼고 가족 전체의 실제 수입·지출을 계산합니다.

🔒 올린 파일은 서버로 전송되지 않고, 이 컴퓨터의 브라우저 안에서만 읽고 저장됩니다. (가계부 화면과 따로 저장)

1. 통장·카드 등록

📂 회준 통장·카드 파일을 한 번에 끌어다 놓기 또는 눌러서 선택 · 여러 파일 가능
📂 보현 통장·카드 파일을 한 번에 끌어다 놓기 또는 눌러서 선택 · 여러 파일 가능
통장마다 생활비·비상금 같은 용도를 추측합니다.
➕ 통장·카드 직접 등록 (선택)

계좌 끝자리를 넣어 두면 파일을 올릴 때 그 계좌를 자동으로 골라 줍니다. 이름·소유(공동 포함)는 아래 목록에서 바로 고칠 수 있습니다.

    2. 이 달의 실제 합계

    통장끼리 옮긴 돈은 수입·지출에서 뺍니다. 카드는 통장에서 빠져나간 카드대금을 지출로 계산하고, 카드 사용 내역은 참고로만 보여 줍니다.

    📌 고정 지출

    매달(격월·분기) 같은 날짜 무렵(±4일)에 거의 같은 금액으로 나가는 출금을 자동으로 찾습니다. 아니면 「삭제」, 빠진 항목은 아래 계좌별 내역에서 「📌 고정으로」를 누르면 이름이 같은 출금이 한 항목으로 묶입니다.

    3. 🔁 돈의 이동

    한 통장에서 나간 금액과 같은 금액이 다른 통장에 10분 안에 들어오면 자동으로 「내부 이동」으로 묶습니다. 2시간 안이거나 같은 금액이 여러 건이라 헷갈리면 아래에서 물어봅니다.

    확인이 필요한 이동 (전체 기간)

    찾은 내부 이동

    짝 없는 이체

    이체처럼 보이지만 짝을 못 찾은 거래입니다. 등록하지 않은 우리집 계좌(예: 증권·청약 계좌)와 오간 돈이면 「우리집 이동으로 보기」를 눌러 합계에서 빼세요.

    4. 🧭 계좌 간 흐름

    어느 통장에서 어느 통장으로 얼마가 옮겨졌는지 보여 줍니다. (가로줄 = 보낸 계좌, 세로칸 = 받은 계좌)

    5. 💳 카드대금 확인

    카드대금은 사용한 다음 달에 빠져나가고, 선결제·할부·리볼빙이 있으면 사용액과 달마다 차이가 납니다. 몇 달을 합치면 비슷해지는지 확인하세요.

    6. 🧾 계좌별 내역

    흐리게 보이는 줄은 합계에서 빠진 거래(내부 이동·카드 사용 참고)입니다. 금액 아래 작은 숫자는 거래 후 잔액입니다.
